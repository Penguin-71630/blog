## Overflow Detection

### Unsigned

ALU：看 MSB 的 carry out。

MIPS：
```asm
addu $t0, $t1, $t2

nor  $t3, $t1, $zero  # 0xFFFFFFFF - $t1
sltu $t3, $t3, $t2
bne  $t3, $zero, Overflow
```

### Signed

ALU：看 MSB 的 carry in $\oplus$ carry out。

MIPS：
```asm
addu $t0, $t1, $t2

xor  $t3, $t1, $t2
slt  $t3, $t3, $zero
bne  $t3, $zero, No_Overflow

xor  $t3, $t0, $t1
slt  $t3, $t3, $zero       # 兩個同號數相加溢位 iff 有變號
bne  $t3, $zero, Overflow
```

### Booth's Algorithm

假設要算 $C \times$ `0111110`，一般的乘法器會做 5 次加法：
$$
C \times (2^5 + 2^4 + 2^3 + 2^2 + 2^1)
$$
利用 $2^n - 1$ 的技巧，將連續的 1 合併成兩個 2 的冪次方相減，可以減少加法的次數。
$$
C \times (2^6 - 2^1)
$$

### MIPS Multiplication

- `$HI`: High 32 bits of the result
- `$LO`: Low 32 bits of the result

```asm
mult $rs, $rt  # HI|LO = rs x rt
mfhi $rd       # rd = HI
mflo $rd       # rd = LO

# pseudo-instruction
mul  $rd, $rs, $rt  # rd = (rs x rt)[31:0]
```

## Floating Point 




### Fixed-Point Representation

固定小數點的位置，也就是說每個 bit 能表達的數是固定的。

```
8   4   2   1   |   1/2   1/4   1/8   1/16

0   0   0   0   .    0     0     0     0
```

最大的問題就是能表達的數太少。


### IEEE 754 Floating Point Representation

使用類似科學記號的方式表達浮點數，優點是可表示的數範圍較大，小缺點是數字特別大時精度也會被放大，但這已經是非常優秀的折衷方案了。

```
┌──────────┬──────────────┬──────────────────┐
| Sign (S) | Exponent (E) |    Mantissa (M)  |
|    (1)   |      (8)     |       (23)       |
└──────────┴──────────────┴──────────────────┘
```
<InfoBox>
- Sign $(S)$: $0$ 正 $1$ 負
- Exponent $(E)$: biased exponent
    1. 將 $E$ 看成 unsigned $(0 \sim 255)$
    2. 減去 bias $= 127$ $(-127 \sim 128)$，得到實際的指數
    3. $-127, 128$ 是給特殊數字使用，也就是說單精度浮點數指數的範圍是 $2^{-126} \sim 2^{127}$
- Mantissa $(M)$ (aka Significand): 類似科學記號的尾數，範圍是 $1.000...000_{(2)} \sim 1.111...111_{(2)}$，但因為開頭永遠都是 $1$，所以直接省略，只存後面的小數。
    - 範例：$1.375$ 對應到 $M = $ `01100000000000000000000`
</InfoBox>

IEEE 754 單精度浮點數公式如下：
$$
\text{實際數字} = (-1)^S \times 1.M \times 2^{E-127}
$$

<InfoBox style="info">
**Q：為什麼用 signed exponent（直接把 exponent 當作有號整數對待）？**

因為這樣可以讓浮點數的比較、排序變得更容易，因為我們可以直接比較兩個浮點數的位元，而不需要考慮 sign bit。
</InfoBox>

<InfoBox style="info">
**Q：以單精度為例，為什麼用 bias 要 127，而不是 128？**

還沒查到是什麼原因，感覺可能是為了科學運算讓指數大一些？
</InfoBox>


<InfoBox style="warning">
**特殊數字表達方式**

|  | $E$ 全部都是 $0$ | $E$ 全部都是 $1$ |
|---|:---:|:---:|
| **$M = 0$** | $\pm 0$ | $\pm \infty$ |
| **$M \neq 0$** | Subnormal | NaN |

**\# 關於 NaN**

整數除以 0 會直接觸發 exception，浮點數設計了 INF 和 NaN 因此除以 0 時通常不會直接掉進 exception（Default Non-stop Computing），方便一些數值運算的進行。
