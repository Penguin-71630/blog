## 筆記


- `#include` 只是複製貼上，不會動用到 linker。
- static 且 unused 的函式會被編譯器優化掉（使用 `objdump -r` 會看不到該函式的 entry）。
- `nm` 可以列出 `.o` 檔的 symbol table。
