## 資料分類:硬資料 vs 軟資料

回傳前端的 JSON 中,建議每個欄位附上來源與信心度:

| 類別 | 取得方式 | 處理方式 |
|---|---|---|
| **硬資料** | API 直接欄位 | `confidence: 1.0`,直接使用 |
| **軟資料** | LLM 從評論文字抽取 | 標註信心度,提供 evidence |
| **缺失資料** | 完全無來源 | 不顯示,或提示「請至 XXX 確認」 |

範例 JSON 格式:

```json
{
  "name": "店家名稱",
  "rating": {
    "value": 4.3,
    "source": "google_places",
    "confidence": 1.0
  },
  "has_outlet": {
    "value": true,
    "source": "review_extraction",
    "confidence": 0.7,
    "evidence": ["評論中 5 則提到有插座"]
  },
  "opening_hours_warning": {
    "needs_social_check": true,
    "reason": "店家網站為 Instagram,可能有臨時公告"
  }
}
```
